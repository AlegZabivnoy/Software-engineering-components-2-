# ADR 0005: Component діаграма в PlantUML

## Контекст
Завдання 5 вимагає компонентну модель архітектури: компоненти, provided/required-інтерфейси, залежності, межу системи та зовнішні інтеграції. Діаграма має бути у декларативному синтаксисі з рендером

## Розглянуті альтернативи

**Варіант A — Mermaid flowchart**
* Плюси: GitHub рендерить без додаткових кроків; усі інші діаграми проєкту в Mermaid
* Мінуси: немає нотації інтерфейсів (provided/required); компоненти доводиться імітувати вузлами, і діаграма перестає бути UML Component Diagram

**Варіант B — Mermaid C4**
* Плюси: рендериться в Mermaid, є рівні контейнерів і компонентів
* Мінуси: це нотація C4, а не UML; немає provided/required-інтерфейсів; синтаксис експериментальний

**Варіант C — PlantUML component**
* Плюси: справжня UML нотація компонентів та інтерфейсів, межа системи через `rectangle`; PlantUML уже використано для `use-case.puml`
* Мінуси: GitHub не рендерить `.puml`, потрібен окремий PNG

## Рішення
Обрано варіант C: дві діаграми PlantUML — оглядова `Diagrams/component-overview.puml` і зум у Backend `Diagrams/component-backend.puml` з рендерами `overview-render.png` і `backend-render.png`

## Наслідки
* Поруч із `.puml` лежить PNG, його треба оновлювати разом із кодом
* Решта діаграм лишається в Mermaid
