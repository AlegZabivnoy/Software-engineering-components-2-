# Software-engineering-components-2-

## Домен: Онлайн-магазин техніки

### 1. Опис предметної області
Система представляє з себе платформу електронної комерції, що спеціалізується на продажу різної техніки (смартфони, ноутбуки і тд)

### 2. Ключові процеси
* **Каталогізація:** розподіл за категоріями (ноутбуки, смартфони, ігрові консолі та інше) та виробниками 
* **Складський облік:** відстеження наявних залишків товарів за артикулами (SKU)
* **Оформлення замовлень:** об'єднання обраних товарів клієнта в єдину заявку із зазначенням кількості одиниць
* **Відстеження статусів:** контроль життєвого циклу замовлення (створено, оплачено, відправлено, виконано)

### 3. Структура репозиторію
* `spec.md` — сутності, атрибути, зв'язки
* `diagram.mmd` — декларативний код ER діаграми у синтаксисі Mermaid
* `DEFENSE.md` — точка входу для рев'ю результатів аудиту моделі (топ-3 виправлення коміти)
* `adr/` — ADR на ключові рішення (за MADR)
